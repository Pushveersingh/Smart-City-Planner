# Smart City Planner

## Project Overview
Smart City Planner is a mini-project developed as part of the Design and Analysis of Algorithms (DAA) subject. The project aims to make city planning easier by managing different city locations and finding efficient routes between them.

It uses graph-based algorithms to represent city locations and roads, calculate shortest paths, and help users find the best routes between different places.

## Objectives
- To understand and implement graph data structures.
- To find the shortest path between two locations.
- To apply Design and Analysis of Algorithms concepts.
- To improve route planning and connectivity in a city.
- To understand the practical applications of graph algorithms.

## Features
- Add and manage city locations.
- Connect different locations through roads.
- Display the city route network.
- Find the shortest route between two locations.
- Calculate route distances.
- Optimize travel paths using graph algorithms.

## Algorithms and Concepts Used
- **Graph:** Represents city locations as vertices and roads as edges.
- **Dijkstra's Algorithm:** Finds the shortest path between two locations.
- **Breadth-First Search (BFS):** Traverses connected city locations.
- **Adjacency List:** Stores connections between different locations.
- **Greedy Approach:** Used in shortest-path selection through Dijkstra's algorithm.
